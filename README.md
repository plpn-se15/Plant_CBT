# Plant_CBT
생물분류기Plant Taxonomy CBT (식물분류기사 실기 대비 프로그램)
생물분류기사 식물 실기 시험을 대비하기 위한 Flask 기반의 고효율 인터랙티브 CBT 웹 애플리케이션입니다. 

🚀 주요 기능
실전 모의고사: 20문제 또는 50문제 세트를 무작위로 추출하여 실전 감각을 기릅니다.

핵심 3개 평가 항목: 과, 종명, 멸종위기종 여부 각각 입력을 통해 집중도 높은 암기 및 테스트가 가능합니다.

키보드 중심 네비게이션:

Tab: 입력 칸 및 버튼 순차 이동
방향키 ← / →: 복수 이미지 슬라이드 전환
Ctrl + 마우스 휠: 이미지 확대/축소 및 디테일 관찰
Space: 멸종위기종(-, Ⅱ, Ⅰ) 단계 선택 단축키
Enter : 다음 문제 또는 채점(마우스 버튼으로도 가능)
종 검색 도감: 원하는 식물명을 검색하여 분류 정보와 다중 이미지를 미리 학습할 수 있습니다.

맞춤 모의고사: 취약한 식물들만 골라서 나만의 시험 범위를 설정해 응시할 수 있습니다.

🛠️ 설치 및 실행 방법
파이썬 라이브러리 설치: 터미널에 입력합니다. 초기 설정에 필요합니다.
 pip install flask pandas


2. 프로그램 실행:
Bash
python app.py

3. 브라우저 접속:
http://127.0.0.1:5000
`Ctrl + 클릭` 으로 웹 애플리케이션 접속.사 식물 실기 공부를 위한 CBT 프로그램.
